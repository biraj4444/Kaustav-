How I think about building

Four decisions from my own projects that show the reasoning, not just the result.

Cut scope when the content is the product

I dropped a full Flask version of AdSense Helper and rebuilt it as a static site. The guide's value was accurate, readable steps, and a backend only added ways to fail.

Seen in AdSense Helper

Motion should carry meaning

In Expressive Send the paper plane shows that a message travels to a person. It is also kept short enough that it never slows a conversation down.

Seen in Expressive Send

Choose the simplest tool that fully solves it

A static page on Cloudflare where that is enough, a Flask application with MongoDB and Google sign-in where it is not. Small dependencies keep the code readable and the pages fast on any screen.

Seen in every project

Ship the unglamorous pages

Terms, privacy, a sitemap, search console readiness and a way to reach me. A project that cannot be trusted or found is not finished.

Seen in AdSense Helper and txtskill
